# こえとも 🎙️

**話しかけるだけで、表情で返事してくれる。**
横向きのスマホに置いておくだけの、しゃべるおともだちです。

🚧 **ただいま正式公開の準備中です。** もうすぐ誰でも話せるようになります！
🎬 **[紹介動画を見る](https://www.youtube.com/watch?v=WwQZj8J0ruk)**

## どんなアプリ？
- 🗣️ **話すだけ**：ボタンを押してしゃべると、声と表情で返事してくれます
- 🎭 **いろんなキャラ**：やさしい「ふつう」のほかに、クレーマー、過保護、冷笑、意識高い系、陰謀論、ドパガキ、論破王まで
- 📚 **勉強モード**：5教科の家庭教師。問題のPDFや写真を読み込んで「第3問がわからない」と聞けます
- 🎨 **じぶんで作る**：名前・いろ・かお・せいかく・こえを選んで、自分だけのキャラを作れます。できたキャラは画像にしてシェアもOK
- 🎬 **切り抜き録画**：字幕つきの縦型動画にして保存・共有できます
- ✨ 3Dでぬるぬる動く表示や、指を追いかけてくる「ついてくる」モードも

## つかいかた
1. スマホで [k-z-u.github.io/koetomo](https://k-z-u.github.io/koetomo/) を開く
2. スマホを**横向き**にする（iPhoneは「共有 → ホーム画面に追加」から開くと全画面になります）
3. マイクを許可して、話したいキャラを選んで話しかける

みんなの無料枠で**1日120分**まで話せます（毎日 0:00 にリセット）。自分の Gemini API キーを持っている人は、設定に入れると時間の制限なしで話せます。

## 知っておいてほしいこと
- 話した声は、返事を作るために Google の Gemini に送られます
- 作ったキャラや API キーは、使っている端末の中にだけ保存されます
